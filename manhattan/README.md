# Manhattan Nights

A Three.js city study with 15 buildings, streets and a simplified river.

## Controls
- Drag the left mouse button to look around.
- WASD or arrow keys to move; Q/E to descend/ascend.
- Shift to move faster; R to reset; scroll to move forward/backward.

## Add to an existing GitHub Pages portfolio
Upload the `manhattan` folder beside your portfolio homepage. Keep your existing homepage. Link to `./manhattan/` from your portfolio.

`index.html` is the runnable project. `project.json` is the editable Three.js editor project. Three.js is loaded from jsDelivr, so the page needs internet access. This package does not use P5Sketch.js or the editor export system.

Based on the saved, fully grouped project. If you made later changes in the editor, save that JSON and regenerate this package from the latest file.
